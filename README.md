## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line tip to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program validates the
tip against the competition gate first: 1–200 characters, not only
whitespace. Two runs produce byte-identical output.
